# Sinnfaden 0.4.4

- Fertige Prompts erscheinen sofort mit ihren Eingabefeldern und den Aktionen zum Kopieren und Bearbeiten. Eine freiwillige Übung verdeckt das Ergebnis nicht mehr.
- Die Übung bleibt unter dem Prompt verfügbar. Wer das ausgearbeitete Beispiel gesehen hat, bekommt weiterhin ehrliche Rückmeldung zu einem unterstützten Versuch.
- Sobald Antworttext eintrifft, zeigt Sinnfaden an, dass der Prompt fertiggestellt wird. Unvollständige Antworten werden weiterhin geprüft, bevor sie als Ergebnis erscheinen.
- Design, gespeicherte Daten und bestehende ChatGPT-Verbindung bleiben erhalten.

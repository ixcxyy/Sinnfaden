# Sinnfaden 0.4.5

## Genaueres Feedback beim Lernen

- In „Eine Antwort prüfen“ erkennt Sinnfaden jetzt auch Uhrzeiten wie `16:30` ohne das Wort „Uhr“. Eine versehentlich geänderte Uhrzeit zählt nicht mehr als richtige Lösung.
- Eine Korrektur in die falsche Richtung, etwa „Dienstag mit Mittwoch ersetzen“, wird erkannt.
- Korrekte Schreibweisen wie `16.00 Uhr` werden akzeptiert.
- Gespeicherte Versuche dieser Lektion erhalten beim Öffnen die korrigierte Rückmeldung. Deine Antworten, Zeitpunkte und verwendeten Hilfen bleiben erhalten; falsche Bewertungen zählen nicht weiter zum Lernfortschritt.

Das Design bleibt unverändert. Geprüft wurden außerdem echte Prompts für E-Mails, verständliche Erklärungen, einen Spanisch-Lernplan und einen Essensplan mit konkreten Grenzen.

Diese kostenlose Entwicklungsversion verwendet signierte Updates, aber keine Apple-Notarisierung.
